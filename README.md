# Address Book

## Description

The **Address Book** is a C programming project used to store and manage contact information such as **name, phone number, and email address**.

The project provides basic operations for managing contacts, including:

* **Create** – Add a new contact.
* **Search** – Find a contact using name, phone number, or email.
* **Edit** – Modify existing contact details.
* **Delete** – Remove a contact from the address book.
* **Display** – View all saved contacts.
* **Save** – Store contact information in a file.
* **Load** – Retrieve previously saved contacts when the program starts.

## Technologies Used

* C Programming
* Structures
* Arrays
* Pointers
* Strings
* File Handling
* Dynamic Memory Concepts
* String Functions

## Data Stored

Each contact contains:

* Name
* Phone Number
* Email Address

## File Handling

The project uses a file to permanently store contact information. Contacts can be saved when the program exits and loaded again when the program starts.

## Objective

The main objective of this project is to understand and implement **C programming concepts such as structures, functions, strings, file handling, validation, and modular programming** in a practical application.
